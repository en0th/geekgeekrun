## 修改范围

### 配置执行与任务安全

- 经验编号、编号字符串和旧中文配置共用规范化规则；未知选项明确报错，不默默全部排除。
- 岗位名称关键词按字面包含匹配，例如“产品”可以匹配“产品助理”。分类按任一关键词、描述按每个关键词；名称/分类/描述支持全部或任一，城市、薪资、经验及公司条件仍独立检查，不意味着只要含“产品”就无视其他条件发送。
- 无效表达式拒绝保存或启动；更新/清空关键词删除旧的复合表达式；公司名单兼容旧字符串并保留新数组项中的逗号。
- 薪资单位、薪数、上下限及区间交集统一执行规则。数据库岗位视图增加公司品牌名称；新增视图迁移不删除岗位/公司记录。
- 创建任务冻结条件、来源、方式、公司名单及全局节奏，出队与自动恢复复用快照，不被随后编辑污染。显式恢复不得把收集模式变成打招呼；快照不包含Cookie或API密钥。
- 配置为三步，节奏只在系统设置；多来源顺序轮换并正常结束；运行配置历史、差异对比、空状态引导等沿用本地已确认版本。

### 操作布局与全局主题

- 固定底栏与表单对齐：下一步在末步原位换成开始，只有一个前进主操作；上一步为次操作。44px高度、清晰焦点、窄视口换行和动态底部留白。
- 运行卡片标题区查看本次配置/收起，操作区查看运行进度/暂停，结束单独区分；收起不停止，结束二次确认。
- `app-theme.css` 在Element Plus后全局导入，页面、挂载到body的确认弹窗和通知共用语义色。普通主操作统一蓝色，结束/删除/覆盖确认用红色，而不是所有按钮都蓝色。
- 去掉底栏和运行卡片局部按钮配色；统一通知、旧浏览器页链接，以及资料库导入/过滤/列设置等次要提示文字。

### Win10 玻璃侧栏兼容

- 原生窗口材质与应用内外观分开管理。Win11 22H2+保留acrylic，macOS保留sidebar vibrancy；Win10及早期Win11使用不透明原生窗口，不调用不支持的backgroundMaterial。
- 应用内色彩背景、CSS模糊、圆角、高光和边框在非原生材质主机也启用。Win10效果不是透出桌面的原生Acrylic，也不是与Win11折射完全相同的承诺。
- 原生主机保留SVG折射；无模糊支持或要求减少透明度时退为不透明侧栏，高对比度模式去掉装饰。没有新增依赖、强制GPU标志或原生透明库。

参考：[Ant Design按钮语义](https://ant.design/components/button/)、[Electron原生材质平台限制](https://www.electronjs.org/docs/latest/api/browser-window#winsetbackgroundmaterialmaterial-windows)。项目尺寸和颜色是实现选择，不宣称各家公司存在统一强制标准。

## 验证与复现

本地生产构建和Windows x64 NSIS包通过。源码与已验证交付清单逐文件核对（原清单377文件；本PR不提交含本机路径的本地交付说明，而新增本便携说明）。

使用仓库pnpm 8.15.9安装依赖，按`packages/ui/package.json`中的原有`build` / `build:win`脚本构建。

```powershell
# 源码根目录；测试使用支持 test-isolation=none 的较新Node运行时
node --test --test-isolation=none packages/geek-auto-start-chat-with-boss/tests/*.test.mjs packages/ui/tests/*.test.mjs
node --test packages/pm/tests/daemon-queue.test.cjs
# 使用与当前Electron ABI匹配的原生模块补测
$env:ELECTRON_RUN_AS_NODE = '1'
& ./node_modules/electron/dist/electron.exe --test packages/ui/tests/favorites.test.mjs
```

- 普通Node测试114项中111项通过，3项原生数据库测试因ABI不同跳过，之后Electron运行时3项全部通过；Windows队列7项通过，合计121项不同测试通过。
- 实际源渲染器使用隔离IPC，经缓存Playwright Chromium验证：1920×1080、1440×1000、1024×768、720×800视口，60项流程与70项样式断言通过。原生窗口最小尺寸未更改，窄浏览器视口只是压力检查。
- 覆盖六个主页面、六个设置页签、表格小弹窗、按钮状态、启动/缺项定位、配置快照、收起、暂停/恢复、结束确认，以及原生/非原生/无模糊/减少透明度分支。页面及控制台错误0。旧隔离适配器有12/20条不支持IPC警告，生产包验证不含模拟代码。
- 已打包程序检查SQLite原生模块、筛选规则、版本与主题产物，并通过隔离旧库升级保留数据验证。

建议人工路径：找岗位→下一步→开始确认；运行卡片→结束→取消，确认仍运行；资料库→列设置/导入/过滤；设置→浏览器/运行节奏；Win10检查侧栏折叠和提示文字。

**边界**：这些构建和界面检查来自本地0.21.3交付验证，不是本PR的GitHub CI结果。没有真实BOSS发送或真实账号测试。宿主为Win11，Win10能力分支模拟通过但未Win10实机验收；macOS原生分支代码回归通过，但未重建或实测macOS包。Windows安装包未数字签名。
