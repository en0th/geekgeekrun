## 改动

### 岗位/JD 屏蔽词

「找岗位 → 职位筛选与来源 → 投递前必需条件」新增「岗位/JD屏蔽词」。名称或描述包含任一词就跳过，按字面子串比较，忽略大小写并统一全角/半角。不需要用户编写正则，`C++` 等字符不会被当作表达式。

这是独立硬条件，正向名称/分类/描述的「满足其中一项」不会放宽它。启用后缺少名称或描述也会跳过；始终不因为屏蔽词执行标记或冷却。「只收集全部岗位」继续忽略求职条件。

统一规则用于实际筛选、预览和最终发送闸门；配置保存、公共条件、模板、任务快照保留整个条件对象。旧配置默认不启用：

```json
{
  "requiredJobConditions": {
    "excludedWords": ["外包", "驻场", "C++"]
  }
}
```

实现：[统一条件](../packages/geek-auto-start-chat-with-boss/job-filter-config.mjs)、[界面及预览](../packages/ui/src/renderer/src/page/Ux/index.js)。

### 浏览句柄

原 `openJobCardForReview` 每次调用 `list.$$('li.job-card-box')`，为整批卡片创建远程句柄，再点击其中一个，且没有释放这些句柄。现在只取目标卡片的一个句柄，并在点击成功、卡片缺失或点击失败时释放；保留选中岗位与详情 ID 的核对。

1000 张卡片、连续查看 100 个岗位的隔离测试中，新实现只创建 100 个句柄，同时持有峰值为 1，结束后为 0；同时验证卡片缺失、脱离 DOM 和旧详情不能放行。这里验证的是句柄数量，不是实际浏览器 RSS 或网站吞吐提升比例。真实只收集任务也已走过新的点击路径。

实现：[auto-chat-navigation.mjs](../packages/geek-auto-start-chat-with-boss/auto-chat-navigation.mjs)、[句柄回归](../packages/geek-auto-start-chat-with-boss/tests/detail-handles.test.mjs)。

### 历史查询

将 `DATE(date) >= DATE(cutoff)` 改为日期列直接与 UTC 当日零点比较，并增加 `(encryptCurrentUserId, date)` 组合索引。保留旧规则的 UTC 日边界、按当前登录身份恢复历史及无身份时返回空集合的行为。

迁移只增加索引，不改动历史记录。原生测试调用实际 TypeORM 查询，在截止前 1ms、截止瞬间、当日和另一登录身份样本上验证结果，并对实际生成的 SQL 执行 `EXPLAIN QUERY PLAN`，确认两张日志表均使用日期范围索引。

10 万条内存 SQLite 合成数据，其中 180 条符合条件；5 个独立进程，各预热 3 次、测量 15 次，先取每进程中位数，再取 5 个结果中位数：

| 项目 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 单次查询中位数 | 5.972ms | 0.0345ms |
| 返回记录 | 180 | 180 |
| 查询计划 | 全表扫描 | 账号和日期范围索引 |

该样本创建索引的耗时中位数为 32.38ms。这些是局部数据库测量，不代表真实 BOSS 采集或投递同比提速；真实库中的迁移也已成功执行。

实现：[历史查询](../packages/sqlite-plugin/src/handlers.ts)、[索引迁移](../packages/sqlite-plugin/src/migrations/1792454700000-IndexAccountHistory.ts)、[边界和查询计划测试](../packages/sqlite-plugin/tests/history-index.test.cjs)。
