# 0.23.9：浏览器就地恢复与来源拖拽排序

找岗位任务遇到详情切换或页面加载异常时，原恢复流程会关闭浏览器重建。现在只要原任务浏览器仍连接、页面仍存在，就会清理旧监听和旧工作、保留该浏览器，再从任务原位置重新核对。浏览器确实断开或页面已关闭时才重新打开。

复用窗口时不会重新注册数据采集钩子，不会用保存的登录信息覆盖当前浏览器会话；仍然核对账号、岗位身份和任务原有条件。手动选择的岗位不会自动成为可发送目标。

切换岗位会撤销旧详情请求。已被新请求替代的旧响应无法读取时，不再把它记为当前页面失败，也不等待废弃响应到超时。当前响应仍严格检查；即使是旧响应，明确返回登录失效、验证码或访问限制时也保留拦截。

结束任务操作统一为“结束任务”红色描边按钮，运行卡片、异常处理卡片和任务详情使用同一个按钮生成函数。暂停保留独立语义；结束任务仍需确认，已有数据保留。

来源切换顺序使用拖拽手柄，移动时显示选中样式、占位和180毫秒排序动效；系统开启减少动态效果时关闭位移动画。支持Alt＋上下方向键调整顺序，提供读屏结果播报。顺序自动保存，未启用来源的配置与位置保留，正在运行的任务仍使用启动时的快照。

单次预约的名称统一为“定时启动”。当前功能只在指定时间执行一次；“定时任务”容易被理解为每天或每周重复，因此没有借改名增加重复执行功能。电脑和软件需要保持运行，错过启动时间仍不自动补跑。

对比操作路径：

- 找岗位 → 职位筛选与来源 → 来源切换顺序：拖动每行右侧的六点手柄，放开后自动保存。
- 找岗位 → 开始前确认 → 定时启动：选择单次启动时间；任务列表中的“定时启动”区可查看或取消。
- 找岗位运行卡片、异常卡片、任务详情：结束操作均为红色描边“结束任务”。
- 运行中的BOSS浏览器：手动切换岗位后如需恢复，保留可用窗口重新核对；仍以任务原条件为准。

离线验证覆盖取消旧请求、新响应及迟到的限制响应、原浏览器和登录不被替换、排序数据保存、真实拖拽与键盘调整、结束按钮样式。未使用真实账号发送；实际BOSS页面交互仍需安装后验证。
