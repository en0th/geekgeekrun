# 任务列表

「任务列表」展示后台守护进程中的任务运行情况，两个标签页共用工具栏：**过滤 / 常用条件 / 统计 / 导出 / 列设置 / 全屏 / 刷新**。

## 当前任务

![任务列表 · 当前任务](assets/ux-tasks-current.png)

列：方式、状态、进度、开始 / 加入时间、已用时间、现在在做、操作。空状态提示「还没有运行中的任务，配置好条件就能开始」，可点「去配置找岗位」直接跳转。

任务详情可展开“查看本次累计用量”，查看岗位接口请求、详情请求和累计运行时间的用量／上限。达到运行保护上限后，先到“设置 → 任务运行”选择并保存运行模式，再回任务列表继续；新上限仍无余量时需结束本轮再新建，累计用量不会因继续或换来源清零。请求包含失败和重试，与保存岗位数不同；验证、暂停、排队和退避等待不计运行时间。旧任务启用保护前的用量未知时会单独提示。

退出应用时，会先保存任务检查点、关闭所属浏览器并停止排队任务，再断开守护进程；重启后可继续同一找岗位任务，处理数量、排除集合和预算接着累计。恢复开始时保留原统计，不先归零。若要让本次任务以后不能再恢复，使用“结束任务”。页面筛选无法确认时同样会保留进度并指出字段，检查后可恢复。

![预算耗尽后的任务详情，隔离示例](assets/ux-run-budget-progress-2026-10-20.jpg)

达到每日目标时，可查看结果或明确为今天追加数量；已达到账号软件保护上限、平台拒绝开聊或发送结果待核对时，任务继续保持停止。待核对发送需先在BOSS检查结果，再点击“处理已核对记录”确认计入已用数量，随后结束旧任务、按需新建，不会自动重发。

“定时启动”是单次执行。电脑和应用需保持运行，到期按保存的账号和配置串行提交；错过时间不会自动补跑，有未处理的旧任务时不会替换其进度，可在任务列表查看原因或取消待启动记录。

## 历史记录

![任务列表 · 历史记录](assets/ux-tasks-history.png)

列：方式、状态、开始时间、结束时间、用时、说明、操作。空状态提示「运行过的任务会出现在这里」。

只收集任务的“查看详情 → 本次数据”按运行编号显示实际采集的岗位，可切换“本轮采集 / 本轮新增”。新增指本次任务首次进入本地资料库的岗位；暂停恢复沿用同一编号，旧数据和导入数据不会被算作本轮新增。台账启用前的采集无法重建完整任务归属。

此处也能生成当前范围的岗位摘要，或点“在资料库查看本轮新增”跳转为首次任务编号过滤。岗位详情及摘要使用资料库当前保存的内容。

全部使用明确搜索来源的新任务还可切换“较同范围基准新增”：按同账号、同冻结搜索及筛选配置，自动与较早且有采集记录的最近任务比较岗位 ID，并显示基准编号、增加、重复及本轮未观察到的数量。“刷新比较”重新读取台账。旧任务、含个性化推荐的任务、恢复时混合了账号/范围的任务，以及没有同范围基准的任务会显示不可比较的原因。

这与本库首次发现是不同口径。预算或中断可能导致采样不完整；增加不表示平台新发布，本轮未观察到也不表示下架。台账数量包含已删除详情的岗位，列表、导出、统计与摘要只显示仍保存详情且满足当前过滤的岗位。

![本轮新增（隔离示例）](assets/ux-job-discovery-2026-10-20.jpg)

> 任务由后台守护进程串行执行：同一时间只有一个任务在「现在在做」，其余排队等待。
