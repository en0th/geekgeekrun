# 牛人快跑 · GeekGeekRun

一款可以帮助你在 BOSS直聘 上**自动批量开聊 BOSS** 的脚本，基于 Puppeteer。

> 与每一位牛人站在一起。
> - 使命：用科技让复杂的求职过程变简单
> - 愿景：天下没有难找的工作，天下牛人都有满意的工作

各行各业，无论你是小白还是大佬，都能通过几步简单的配置，快速开始求职。

![启动页](assets/bootstrap-splash.png)

## 这是什么

GeekGeekRun（牛人快跑）通过模拟用户在 BOSS直聘网页上的操作，帮助你：

- **批量自动打招呼**：按你配置的条件筛选岗位，自动向匹配的招聘者（BOSS）发送招呼语；
- **只收集、不开聊**：也可以只收集符合条件的岗位数据，供你事后人工处理；
- **已读不回自动复聊**：对已读但未回复的会话，按规则自动补充消息跟进；
- **求职数据归档**：开聊记录、已跳过/已标记记录、职位库、BOSS库、公司库、收藏夹自动沉淀在本地数据库；
- **简历 + 大模型匹配**：本地编辑简历，接入兼容 OpenAI SDK 的大模型（如 DeepSeek）做职位匹配与消息生成；
- **任务队列 + 定时运行**：后台守护进程串行执行任务，可配置运行节奏、定时休息，运行日志与数据库备份齐全。

## 界面总览

主界面为左侧导航 + 右侧内容区，分为三个分组：

| 分组 | 页面 | 说明 |
| --- | --- | --- |
| 逛BOSS | 找岗位 | 配置并开始「批量开聊 / 只收集岗位」 |
| 逛BOSS | 消息跟进 | 已读不回自动复聊配置 |
| 逛BOSS | 自己逛 | 直接打开 BOSS直聘网站手动浏览 |
| 数据 | 求职记录 | 已开聊 / 已跳过·已标记 记录 |
| 数据 | 资料库 | 职位 / 收藏夹 / 招聘者(BOSS) / 公司 |
| 系统 | 任务列表 | 当前任务 / 历史记录 |
| 系统 | 设置 | 账号、浏览器、AI模型、通知、模板、节奏、数据 |

各页面的详细说明与截图见侧边栏「页面指南」部分。

## 快速开始

1. **安装**（见下文「安装方式」），启动后首次会进入「初次使用必读」——逐条勾选接受后进入主界面。
2. **配置浏览器**：设置 → 浏览器，自动检测或手动选择本机 Chrome/Edge。
3. **登录 BOSS直聘**：设置 → 账号与登录，通过 BOSS登录助手获取 Cookie 登录凭证。
4. **配置 AI 模型**（可选，用于「已读不回自动复聊」与职位匹配）：设置 → AI模型配置。
5. **找岗位**：配置运行方式、职位筛选与来源、处理方式，点击「开始收集」或「开始打招呼」。
6. **跟进消息 / 查看记录**：在「消息跟进」「求职记录」「资料库」中查看结果。

更完整的步骤见 [快速开始](Quick-Start)。

## 系统要求

- **Windows（x86_64）**：最低 Windows 10 1507（2016 年后出厂、默认安装 Win10 的电脑一般均可）。
- **Linux（x86_64）**：支持包含默认桌面环境的 Ubuntu 20.04；其它发行版及桌面环境暂未测试。
- **macOS（Apple Silicon、x86_64）**：支持 Sonoma 14.0；更早系统暂未测试。

## 安装方式

各平台均从发行版页面下载安装包：<https://github.com/geekgeekrun/geekgeekrun/releases>

- **Windows**：下载 `.exe` → 双击安装 → 自动启动并引导初次配置。
- **Linux**：下载 `.deb` → `dpkg` 安装 → 从桌面启动。
- **macOS**：下载对应架构的 `.dmg` → 拖入 Applications。发行包未签名，若提示「已损坏无法打开」，在终端执行：

  ```sh
  sudo spctl --master-disable
  xattr -cr /Applications/GeekGeekRun.app
  ```

- 请**注意节制**，建议当天开聊次数用尽后隔几天再使用，并建议使用专用新账号。
- 本程序**完全免费、无内置付费功能**；付费“购买”到的很可能是修改版。
- 本程序**不对你的求职过程与结果负责**，请自行甄别公司与 Offer。
