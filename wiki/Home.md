# 牛人快跑 · GeekGeekRun

按求职条件查找、收集和管理 BOSS直聘岗位；需要时可明确开启自动打招呼或消息跟进。

本 Wiki 对应本仓库 `master` 的桌面界面，当前源码版本为 **0.23.9**。下载安装包时，请在[发行版页面](https://github.com/en0th/geekgeekrun/releases)选择 `ui-v` 开头的桌面版本。

> 与每一位牛人站在一起。
> - 使命：用科技让复杂的求职过程变简单
> - 愿景：天下没有难找的工作，天下牛人都有满意的工作

各行各业，无论你是小白还是大佬，都能通过几步简单的配置，快速开始求职。

## 这是什么

GeekGeekRun（牛人快跑）通过模拟用户在 BOSS直聘网页上的操作，帮助你：

- **批量自动打招呼**：按你配置的条件筛选岗位，自动向匹配的招聘者（BOSS）发送招呼语；
- **只收集、不开聊**：也可以只收集符合条件的岗位数据，供你事后人工处理；
- **已读不回自动复聊**：对已读但未回复的会话，按规则自动补充消息跟进；
- **求职数据归档**：开聊记录、已跳过/已标记记录、职位库、BOSS库、公司库、收藏夹自动沉淀在本地数据库；
- **简历与 AI 辅助**：本地编辑简历，按需配置模型连接、请求超时、重试和思考选项，供消息跟进等辅助功能使用；
- **任务队列与定时启动**：任务串行执行，支持单次定时启动、按分钟休息、账号每日目标和中断后保留进度。

## 界面总览

主界面为左侧导航 + 右侧内容区，分为三个分组：

| 分组 | 页面 | 说明 |
| --- | --- | --- |
| 逛BOSS | 找岗位 | 配置并开始「批量开聊 / 只收集岗位」 |
| 逛BOSS | 消息跟进 | 已读不回自动复聊配置 |
| 逛BOSS | 自己逛 | 直接打开 BOSS直聘网站手动浏览 |
| 数据 | 求职记录 | 已开聊 / 已跳过·已标记 记录 |
| 数据 | 资料库 | 职位 / 收藏夹 / 招聘者(BOSS) / 公司 |
| 系统 | 任务列表 | 当前任务 / 历史记录 |
| 系统 | 设置 | 账号与浏览器、任务运行、AI助手、通知提醒、数据管理、关于与更新 |

各页面的详细说明与截图见侧边栏「页面指南」部分。

## 快速开始

1. **安装**（见下文「安装方式」），启动后首次会进入「初次使用必读」——逐条勾选接受后进入主界面。
2. **配置浏览器并登录**：设置 → 账号与浏览器，选择 Chrome/Edge，通过 BOSS登录助手完成登录。
3. **先收集岗位**：在找岗位中选择“先收集岗位”，保留“只收集符合条件的岗位”，填写求职条件与来源后开始收集。
4. **查看结果**：资料库 → 职位可查看和比较收集结果；任务列表可暂停、继续或结束本次任务。
5. **按需开启开聊或跟进**：自动打招呼需要明确选择、配置处理方式并确认；AI 连接等辅助设置可按需要配置。
6. **调整运行偏好**：设置 → 任务运行可选择模式、分钟制定时休息和每日自动打招呼目标。

更完整的步骤见 [快速开始](Quick-Start)。

## 安装包与运行环境

从[本仓库发行版页面](https://github.com/en0th/geekgeekrun/releases)选择 `ui-v` 开头的桌面版本，按系统和处理器架构下载；各版本的运行要求以对应发行说明为准。

- **Windows（x64）**：下载 `.exe` 安装包后安装。
- **Linux（x64 桌面环境）**：下载 `.deb` 并通过系统的软件安装工具安装。
- **macOS**：Apple Silicon 选择 `arm64`，Intel 选择 `x64` 的 `.dmg`，将应用拖入 Applications。首次打开需要确认时，请先核对来源，再按 [Apple 官方打开 App 指引](https://support.apple.com/zh-cn/102445)操作，为该应用确认打开。

- 本程序仅把你的 Cookie 存储在本地并仅在访问 BOSS直聘时使用，**不会泄露给第三方**；请勿向他人泄漏你的 Cookie。
- 请**注意节制**，建议当天开聊次数用尽后隔几天再使用，并建议使用专用新账号。
- 本程序**完全免费、无内置付费功能**；付费“购买”到的很可能是修改版。
- 本程序**不对你的求职过程与结果负责**，请自行甄别公司与 Offer。
