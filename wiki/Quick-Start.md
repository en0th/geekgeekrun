# 快速开始

从零到「开始打招呼」的完整流程。首次启动会先进入[初次使用必读](Assistant-First-Run)，勾选接受后进入主界面。

## 第 1 步 · 配置浏览器

进入 **设置 → 浏览器**：

1. 点击「自动检测」，程序会自动寻找本机已安装的 Chrome / Edge；
2. 若自动检测失败，点击「手动选择」指定浏览器可执行文件；
3. 点击「保存浏览器配置」。

> 也可以使用「下载浏览器」让程序通过 Puppeteer 下载一个受控浏览器。

详见 [浏览器助手](Assistant-Browser) 与 [设置 · 浏览器](Screens-Settings#浏览器)。

## 第 2 步 · 登录 BOSS直聘

进入 **设置 → 账号与登录**，点击「编辑登录凭证」打开 [BOSS登录助手](Assistant-Cookie)，通过短信验证码 / 二维码 / 微信小程序登录你的 BOSS直聘账号，Cookie 会自动填入。成功后状态显示为已登录。

## 第 3 步 · （可选）配置 AI 模型

若使用「已读不回自动复聊」或需要大模型辅助匹配职位 / 生成消息，进入 **设置 → AI模型配置**，选择一个兼容 OpenAI SDK 的服务商（如 DeepSeek）并填写 API Secret。详见 [大语言模型设置](Assistant-LLM)。

## 第 4 步 · （可选）编辑简历

进入 **简历编辑**（可从设置或相关入口打开），填写姓名、工作年限、期望职位、期望薪资、个人优势、工作经历与项目经历。简历会作为提示词的一部分用于职位匹配与消息生成。详见 [简历编辑](Assistant-Resume)。

## 第 5 步 · 找岗位（核心）

进入 **找岗位**，按三步向导配置：

1. **运行方式**：选择「自动打招呼」「只收集岗位数据」或「只收集符合求职条件的岗位」；
2. **职位筛选与来源**：填写岗位关键词、职位分类、工作地点与待遇、公司偏好；
3. **处理方式**：设置遇到不符合条件的岗位时如何处理。

点击「开始收集」或「开始打招呼」后，任务会进入后台守护进程的队列串行执行。详见 [找岗位](Screens-Find-Jobs)。

## 第 6 步 · 查看结果

- **任务列表**：实时查看任务状态、进度、用时；详见 [任务列表](Screens-Tasks)。
- **求职记录**：查看已开聊、已跳过 / 已标记记录；详见 [求职记录](Screens-Records)。
- **资料库**：查看职位库、收藏夹、招聘者库、公司库；详见 [资料库](Screens-Library)。
- **消息跟进**：对已读不回的会话自动复聊；详见 [消息跟进](Screens-Follow-Up)。
